# Code review

When the user requests a code review (including 「レビューして」), read and follow
`.agents/skills/jev-review/SKILL.md`. Use Jev to triage complete changed files plus
their diffs, then finish the detailed review of flagged or uncertain files and
relevant dependencies. If Jev is unavailable, state that and perform a normal
review. Editing files alone does not trigger this workflow.
